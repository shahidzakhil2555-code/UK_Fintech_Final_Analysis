# UK Fintech Transaction Analysis | Power BI Dashboard



## 📌 Project Overview

This project focuses on analyzing UK fintech transaction data using **Microsoft Power BI**. The dashboard provides insights into transaction trends, payment channels, regional performance, merchant categories, and transaction risk indicators.

The main objective is to transform raw transaction data into meaningful business insights that support transaction monitoring, merchant performance analysis, and risk assessment.

## 🎯 Project Objectives

- Analyze transaction volume and transaction amounts.
- Identify monthly transaction trends.
- Compare transaction activity across different UK regions.
- Analyze transaction channels and transaction types.
- Explore failed transaction reasons and fraud indicators.
- Evaluate merchant performance across sectors and categories.
- Understand the distribution of transaction risk levels.

## 📊 Dashboard Pages

### 1. Executive Summary

Provides an overall summary of fintech transaction performance.

**Key metrics:**
- Total Transactions
- Total Transaction Amount (GBP)
- Number of Regions
- Number of Sectors
- Number of Customers
- Number of Channels
- Number of Customer Segments
- Number of Merchant Categories

**Visualizations:**
- Monthly transaction count
- Monthly transaction amount
- Transaction amount by region
- Transaction count by region

### 2. Transactional Analysis

Focuses on transaction behaviour, payment methods, and transaction characteristics.

**Key analysis:**
- Transaction amount by channel
- Transaction amount by transaction type
- Transaction amount by failed reason
- Transaction fees by channel
- Transaction amount by fraud flag
- Domestic versus non-domestic transactions

**Interactive filters:**
- Region
- Channel
- Device Type

### 3. Merchant Analysis

Evaluates merchant performance and transaction risk patterns.

**Key analysis:**
- Transaction amount by merchant category
- Transaction count by sector
- Risk-flag count by sector
- Transaction amount and count by risk level
- Distribution of low-, medium-, and high-risk flags
- Fraud-flag distribution across merchant categories

## 🔍 Key Insights

Based on the dashboard visualizations:

- The dataset contains approximately **1.5K transactions**.
- The total transaction amount is approximately **£1.90 million**.
- London contributes the highest transaction amount and transaction count among the displayed regions.
- Automated and mobile-app channels contribute substantial transaction values.
- Fraud Suspected is the largest displayed failed-reason category by transaction amount.
- Retail has the highest transaction count among the displayed merchant sectors.
- Low-risk transactions represent the largest group in the displayed risk distribution.

*Note: These insights are based on the dashboard screenshots. They should be validated against the source data and field definitions before being used for business decisions.*
